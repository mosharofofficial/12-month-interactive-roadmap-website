# The Builder's Path — Interactive 12-week AI Engineering Roadmap

A calm, browser-based roadmap designed for a developer who already knows basic MERN CRUD and authentication, and wants to grow into backend/system design, agentic AI, and AI product engineering.

## Run it

- **Simplest:** open `index.html` in a browser.
- **Recommended for local development:** in this folder run `python -m http.server 8080`, then visit `http://localhost:8080`.
- **Publish:** upload this folder to Netlify, GitHub Pages, or any static hosting platform. No build step, database, account, environment variables, or API key is required.

## How to use

1. Click a week card to see its three checkpoints.
2. Click a checkpoint to see **what to learn**, **exactly what proves you're ready to move on**, a small exercise, and what **not** to study yet.
3. Mark complete when you can demonstrate the skill. Progress saves automatically in this browser's `localStorage`.
4. Use **Pick up where you left off** to open the next unfinished checkpoint.

## Pacing

- Intended for **3–4 hours/day**, **6 days/week** (about **18–24 hours/week**).
- Three checkpoints per week is a *suggested* rhythm, not an enforced deadline.
- The project evolves weekly from a catalog API into an AI catalog management assistant.
- The roadmap is a learning plan, not an employment guarantee or a complete course.

## Data and privacy

Completion status is stored **only in the current browser**. There is no tracking or server, and no data sync across devices. Clearing site data or resetting progress clears the saved checks.

## Files

- `index.html`: page structure and accessible modal
- `styles.css`: visual design, layout, and responsive styles
- `app.js`: roadmap content, interactions, and local progress
- `favicon.svg`: vector icon

The website makes no external network requests. It uses local/system fonts for a fast, privacy-friendly experience.
